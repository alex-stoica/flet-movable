# flet-movable

Native bounded dragging. Flet 1.1.x, Flutter 3.47+. Experimental; Android tested.

```sh
pip install flet-movable
```

[Demo](demo/main.py): duration, borders, haptics, JSON start/end/cancel events.
Cancellation restores position. App-managed persistence.

Build demo: `flet build apk --yes`.
Major/minor changes require [release notes](CHANGELOG.md). CI checks tests and packaging.
